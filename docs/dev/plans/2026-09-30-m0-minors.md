# Pendências menores do M0: servidor HTTP, `restart:` e logs do Fx: plano

> **Para quem executa:** execução **inline** com `superpowers:executing-plans` e `superpowers:test-driven-development`. Sem subagentes e **sem passos de commit** (commits propostos no fim, com a autorização do autor, sem trailer de coautoria).

**Objetivo:** um servidor HTTP que para sozinho encerra o processo com código 1; as réplicas do compose voltam sozinhas depois de uma queda; os eventos do Fx deixam de poluir os logs em INFO.

**Arquitetura:** o `observability.ServeOnLifecycle` recebe o `fx.Shutdowner` e o chama com `fx.ExitCode(1)` quando o `Serve` termina com um erro que não é `http.ErrServerClosed`. O `bootstrap` monta o `fxevent.SlogLogger` com `UseLogLevel(slog.LevelDebug)` numa função própria (`fxLogger`). O `x-app` do compose ganha `restart: on-failure`.

**Stack:** Go 1.27.1, Uber Fx v1.24.0 (`fxtest`, `fxevent`), `net/http`, Docker Compose.

**Spec:** [`dev/specs/2026-09-30-m0-minors-design.md`](../specs/2026-09-30-m0-minors-design.md).

## Restrições globais

- `make check` verde ao fim de cada tarefa de código.
- `// Covers: …` e `// Sensitivity: …` como no resto do repositório.
- Mensagens de log estáticas e chaves em `camelCase` (`sloglint`).
- Os erros do Fx continuam em ERROR; só os eventos que não são erro vão para DEBUG.
- Nenhuma política de reinício na infraestrutura (postgres, keycloak, ministack, aws-init, migrate).

## Foco da revisão

1. **O servidor admin (não o da API) para sozinho:** mesmo desfecho, saída com código 1. Os dois chamadores passam o `Shutdowner` (Tarefa 1, Passo 3: conferir os dois).
2. **Stop normal** (`ErrServerClosed`): o `Shutdown` nunca é chamado, e uma parada limpa sai com 0 (Tarefa 1, U31b).
3. **`LOG_LEVEL=debug`:** os eventos do Fx voltam, agora em DEBUG (Tarefa 2, U32, segunda metade).
4. **Um start que falha** (`start failed`, `OnStart hook failed`, `invoke failed`) continua em ERROR com `LOG_LEVEL=info` (Tarefa 2, U32, `invoke failed`; os outros usam o mesmo `logError` do Fx).
5. **`docker compose stop`/`kill` depois do `restart: on-failure`:** a réplica **não** volta sozinha, porque é uma parada manual. As simulações manuais do `docs/testing.md` dependem disso (Tarefa 3, Passo 4).

```go
// Covers: OBS-01 (U32; M0 pending item 3: Fx lifecycle events at DEBUG, Fx errors at ERROR)
func TestFxEventsLogAtDebug(t *testing.T) {
	t.Setenv("DATABASE_URL", "postgres://u:p@localhost:5432/pda")
	t.Setenv("OIDC_ISSUER", "http://localhost:8080/realms/pda")
	t.Setenv("OIDC_JWKS_URL", "http://localhost:8080/realms/pda/protocol/openid-connect/certs")
	t.Setenv("AWS_REGION", "us-east-1")

	// build runs the constructors and invokes of the graph (no start, so no
	// network) with the logger at level, and returns what was logged.
	build := func(level string) string {
		var buf bytes.Buffer
		logTo := fx.Decorate(func() (*slog.Logger, error) { return observability.NewJSONLogger(&buf, level) })
		boom := fx.Invoke(func() error { return errors.New("boom") })
		if app := fx.New(append(bootstrap.OptionsFor(config.Roles{}), logTo, boom)...); app.Err() == nil {
			t.Fatal("fx.New() error = nil, want the failing invoke")
		}
		return buf.String()
	}
	fxEvents := map[string]bool{
		"provided": true, "supplied": true, "decorated": true, "invoking": true, "invoked": true,
		"run": true, "initialized custom fxevent.Logger": true,
	}

	info := build("info")
	failed := false
	for line := range strings.Lines(info) {
		var entry struct {
			Level string `json:"level"`
			Msg   string `json:"msg"`
		}
		if err := json.Unmarshal([]byte(line), &entry); err != nil {
			t.Fatalf("log line %q is not JSON: %v", line, err)
		}
		if fxEvents[entry.Msg] {
			t.Errorf("Fx event %q logged at %s with LOG_LEVEL=info; want it at DEBUG", entry.Msg, entry.Level)
		}
		failed = failed || (entry.Msg == "invoke failed" && entry.Level == "ERROR")
	}
	if !failed {
		t.Fatalf("no ERROR \"invoke failed\" line with LOG_LEVEL=info:\n%s", info)
	}
	if debug := build("debug"); !strings.Contains(debug, `"level":"DEBUG","msg":"provided"`) {
		t.Fatalf("no DEBUG \"provided\" line with LOG_LEVEL=debug; the events must be demoted, not dropped:\n%s", debug)
	}
}
```

// fxLogger writes the Fx lifecycle events at DEBUG, so they do not bury the
// application logs at INFO; Fx errors stay at ERROR (spec of the M0 pending

func fxLogger(log *slog.Logger) fxevent.Logger {

	l.UseLogLevel(slog.LevelDebug)
